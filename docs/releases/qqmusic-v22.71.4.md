## 修复 QQ 点歌搜索与原生插入

- 修正搜索请求参数，解决部分已存在的歌曲在主接口返回空结果、继而受备用接口 HTTP 500 影响的问题。
- 修正原生插入参数的字符串所有权，避免 QQ 清理该参数时把歌曲信息误当作内存管理对象。
- 原生调用正常返回后使用明确的完成标记，不再将未定义的返回寄存器值当作 HRESULT。
- 插入结果不确定时停止后续自动播放、切歌和补插；连接器重新连接也会读取持久事务状态，避免再次发出自动控制命令。
- 保留用户手动播放控制、原静音状态恢复以及未完成事务保护，修正把运行期异常误报为画像校验失败的提示。

原生插入修复限定于已验证的 QQ 音乐 22.71 二进制。未验证的旧播放器分支不会复用这次新增的原生调用地址，历史发布包保持不变。点歌机最低版本维持 1.1.10。

本版只包含 Awoo framework-dependent 小包；正式发布时由既有流程生成签名与哈希。

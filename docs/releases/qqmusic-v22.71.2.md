QQ 音乐连接器 22.71.2，适用于已验证的 QQ 音乐 22.71 客户端。

- 优化「下一首播放」：使用原生窗口消息静默插入，减少启动命令进程带来的等待。
- 加快播放器兼容检查和播放窗口识别，保留原有的兼容画像校验。
- 修复原生回调结束前释放内存的风险；插入结果不确定时停止重试，避免重复插歌。
- 保存插入事务状态，连接器重启后仍能识别未完成操作，并提示先重启 QQ 音乐。

静默插入仅对已验证的 22.71 程序文件启用，支持普通歌曲（song type 0）。其它歌曲类型会在修改队列前明确拒绝。

最低点歌机版本仍为 1.1.10。使用点歌机管理的私有 .NET 8 运行时，旧版连接器和下载地址保持可用。

# QQ 音乐兼容画像

画像只保存版本、模块 SHA-256、机器码前置校验和已验证 RVA，不包含用户数据或播放器文件。

连接器仅在版本、两个 DLL 哈希、目标机器码和全部结构校验同时通过时，才允许调用 QQ 音乐内部的 `AddSongs(mode=0)`。未知版本只生成只读分析报告并拒绝写入进程。

`22.71.json` 对应 `QQMusic2271.00.25.13` 安装构建，保留精确版本和双 DLL 哈希限制。一次现场《Shelter》插入返回 accepted，用户确认下一首位置正确、原队列保留、没有抢焦点且播放正常；完整范围与限制见 [22.71 验证记录](../../docs/QQMUSIC_22_71_VALIDATION.md)。旧版画像保持保留。

外部画像通过 `BILINCM_QQMUSIC_PROFILE_DIR` 指定目录，必须在连接器启动前可用；加载器只读取一次，下载新画像后需要重启连接器。
